# Min Awwalha Charon Short

This folder renders the repository's WAV voiceover using only open-source tools (Whisper, Pillow, FFmpeg). GitHub Actions builds a 1080x1920 Arabic short and uploads the validated video, captions, timestamps and storyboard as a workflow artifact. The original narration remains the only voiceover. No stock imagery, external music, or copyrighted media assets are used.

This README addition initiates the first `push` render job. A successful result requires the GitHub Actions runner to complete; no success is claimed before artifact verification.
